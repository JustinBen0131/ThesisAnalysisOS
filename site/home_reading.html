What can you check for yourself?

After each file edit, the experiment requested all $checks results again. That made $relied requests. When every check listed the files it read, the software ran $trace_executions checks and reused a stale result $trace_wrong times.

Then each check left one input off its list. In $hidden_wrong of those $relied requests, the software used a result whose inputs had changed.
